# Social Contact Collector

Как включить программу с нуля (Termux и Windows) — в `START_RU.md`.

Полная русскоязычная инструкция по установке, настройке и рассылкам находится в `USER_GUIDE_RU.md`.

Инструкция по запуску на Android через Termux и редактированию в Acode находится в `TERMUX_ACODE_GUIDE_RU.md`.

Пошаговая инструкция по получению API и токенов социальных сетей находится в `SOCIAL_APIS_SETUP_RU.md`.

Backend для добровольного сбора и унификации лидов из десяти социальных платформ. Версия принимает webhook-события VK, Telegram, Instagram и Facebook, результаты официальных API X, Reddit и Pinterest и разрешённый импорт LinkedIn, Дзен и Quora.

Версия 0.6.1 содержит модуль ручной публикации комментариев VK через официальный метод `wall.createComment`, автономное JSON-хранилище, комплект запуска для Android без Docker и PostgreSQL и безопасный Cloudflare Tunnel для входящих webhook.

Текущая готовность и оставшиеся задачи указаны в `STATUS.md`.

## Быстрый запуск

### Windows и Docker

1. Скопируйте `.env.example` в `.env` и замените секреты.
2. Запустите `docker compose up --build -d`.
3. Проверьте `GET http://localhost:8080/health`.
4. Получайте лиды через `GET /api/leads` с заголовком `x-api-key`.
5. Откройте `http://localhost:8080/dashboard` и введите `ADMIN_API_KEY`.

### Android, Termux и Acode

1. Распакуйте проект в `Download/social-contact-collector`.
2. В Termux выполните `termux-setup-storage`.
3. Перейдите в проект: `cd ~/storage/downloads/social-contact-collector`.
4. Установите: `bash termux/install-termux.sh`.
5. Запустите: `bash termux/start-termux.sh`.
6. Откройте `http://127.0.0.1:8080/dashboard`.

Для входящих webhook установите туннель и следуйте мастеру:

```bash
bash termux/install-tunnel-termux.sh
bash termux/configure-tunnel-termux.sh
bash termux/start-tunnel-termux.sh
bash termux/configure-webhooks-termux.sh
```

Токены и база хранятся в закрытых каталогах Termux, а общая папка проекта остаётся доступной для редактирования в Acode. После изменения кода выполните `bash termux/sync-termux.sh`.

## Комментарии VK

1. Добавьте аккаунты в `.env` одной JSON-строкой:
   `VK_COMMENT_ACCOUNTS_JSON=[{"id":"main","label":"Основной VK","token":"ВАШ_ТОКЕН","dailyLimit":10}]`
2. Перезапустите приложение: `docker compose up --build -d`.
3. Откройте `/dashboard`, найдите раздел «Новый комментарий VK».
4. Выберите аккаунт, вставьте ссылку вида `https://vk.com/wall-123_456` и напишите текст.
5. Нажмите «Создать черновик», проверьте запись в журнале и отдельно нажмите «Подтвердить и опубликовать».

Токен должен быть получен официальным OAuth-способом и иметь разрешение на публикацию. Токены не возвращаются через API и не показываются в браузере. Программа запрещает одинаковый комментарий к одной записи в течение 24 часов и применяет дневной лимит каждого аккаунта.

## Webhook URL

- Telegram: `https://ваш-домен/webhooks/telegram`
- VK: `https://ваш-домен/webhooks/vk`
- Instagram и Facebook: `https://ваш-домен/webhooks/meta`

Результаты API и разрешённые выгрузки передаются в `POST /api/ingest/:platform` с заголовком `x-api-key`. CSV для CRM доступен в `GET /api/leads.csv`.

На Android публичный HTTPS создаётся встроенными командами Cloudflare Tunnel. Публичный hostname пропускает только `/health` и `/webhooks/*`; панель и административные API остаются локальными. Телефон Telegram принимается только после добровольной отправки пользователем. Meta и VK требуют настройки приложения/сообщества и подписки на нужные события.

## Реализовано

- единая доменная модель лида;
- извлечение и нормализация phone/email/Telegram/URL;
- коннекторы всех 10 платформ; LinkedIn, Дзен и Quora работают через разрешённый импорт;
- проверка webhook-секретов;
- идемпотентная запись события;
- скоринг лидов;
- PostgreSQL и индексы;
- автономное JSON-хранилище с атомарной записью для Termux;
- журнал аудита вставок и обновлений лидов;
- транзакционная очередь доставки лидов в CRM;
- HMAC-подпись, idempotency key и до 10 повторных попыток;
- Docker-конфигурация;
- установочные и управляющие скрипты Android/Termux;
- тестовый и постоянный Cloudflare Tunnel, проверка состояния, журналы и Termux:Boot;
- автоматическая регистрация Telegram webhook и мастер URL/секретов VK и Meta;
- изоляция публичного hostname от панели и административных API;
- health endpoint и защищённый API списка лидов;
- CSV-экспорт и защищённый API импорта результатов API-опроса;
- адаптивная web-панель со статистикой, поиском и фильтрами;
- несколько настраиваемых вариантов сообщений и персональные переменные;
- кампании с расписанием, Lead Score, A/B-распределением и лимитом частоты;
- автоматическая отправка Telegram, VK, Facebook и Instagram при наличии разрешённого диалога и токена;
- ручная проверка сообщений для платформ без разрешённого messaging API;
- стоп-лист, отписка, журнал статусов и повторные попытки;
- модульные тесты.
- комментарии VK от нескольких собственных аккаунтов: черновики, ручное подтверждение, дневные лимиты, защита от дублей и журнал публикаций;
