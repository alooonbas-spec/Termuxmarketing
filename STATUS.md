## Режимы запуска

### Windows или сервер

1. Создать `.env` и установить секреты.
2. Подключить PostgreSQL через Docker Compose.
3. Для webhook использовать сервер с публичным HTTPS-доменом.

### Android

1. Установить Termux и Acode.
2. Выполнить `bash termux/install-termux.sh`.
3. Запустить `bash termux/start-termux.sh`.
4. Открыть `http://127.0.0.1:8080/dashboard`.

Телефонный режим принимает исходящие API-соединения и входящие webhook через встроенный Cloudflare Tunnel. Для постоянной работы требуется домен в Cloudflare и постоянный tunnel token.
